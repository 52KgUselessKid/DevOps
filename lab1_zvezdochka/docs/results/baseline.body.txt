	<h1>A retro multiplayer shooter</h1>
	Teeworlds is a <b>free online multiplayer game</b>, available for
	<b>all major operating systems</b>. Battle with up to
	<b>16 players</b> in a variety of game modes, including
	<b>Team Deathmatch</b> and <b>Capture The Flag</b>. You can even
	<b>design your own maps!</b>

				<div class="topic_title"><a href="?page=news&amp;id=14785">Security update - 0.7.5 released</a></div>
				<div class="topic_info">
					(posted by: <span class="topic_poster">Dune</span>) |
					2020-04-19
				</div>
			</div>

			<div class="topic_text">
				An exploit was discovered, that allows to crash any 0.7 Teeworlds server. Though it does not compromise the security of the host (e.g. no arbitrary accesses in memory) it lets an attacker force a server to repetitively shut down (<a href="https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2020-12066">CVE-2020-12066</a>).<br />
<br />
The 0.7.5 release is a security update that aims to patch this <span class="bold">server</span> exploit. As such, it is very light in features, and is mostly made of fixes. You can find the <a href="https://www.teeworlds.com/forum/viewtopic.php?id=14784">full changelog here</a>. If you are not a server host, it is not necessary to update. If you are hosting a server modification, you should at least consider to apply <a href="https://github.com/teeworlds/teeworlds/commit/c68402fa7e279d42886d5951d1ea8ac2facc1ea5">c68402fa7e2</a>.<br />
<br />
We are still working towards the next release, which will be 0.7.6.

<br />
Ho ho ho! It's Christeemas, Santee is in town, and Teeworlds 0.7.4 is out!<br />
<br />
<span class="bold"><a href="https://www.teeworlds.com/?page=downloads">Download 0.7.4 now!</a></span><br />
<br />
<a href="https://www.youtube.com/watch?v=4KDsXsgw-vY"><img class="postimg" src="https://i.imgur.com/XJ5vvf1.png?1"></a><br />
<br />
Here is a short list of the bigger changes Santee crafted throughout this year: <br />
<br />
+ <a href="https://www.teeworlds.com/forum/viewtopic.php?id=13345">Race mode integration (client side)</a><br />
+ <a href="https://www.teeworlds.com/forum/viewtopic.php?id=13348">In-game server browser</a><br />
+ <a href="https://www.teeworlds.com/forum/viewtopic.php?id=13342">Chat pages &amp; upgrades</a><br />
+ <a href="https://www.teeworlds.com/forum/viewtopic.php?id=13355">Statboard upgrade</a><br />
+ <a href="https://www.teeworlds.com/forum/viewtopic.php?id=13352">Winter background theme</a><br />
+ Wide menus mode<br />
+ Server-side chat commands integration<br />
+ 24 new skins, colorable eyes, and many more body parts to use<br />
<br />
It also includes some optimisations (faster loads...), gameplay adjustments (prevent skipping death tiles, randomize survival spawns) and lots of smaller changes that you can find on <a href="https://www.teeworlds.com/?page=journal&amp;id=13357">the detailed changelog</a>.<br />
<br />
Happy Christeemas!

<br />
Rejoice! Teeworlds 0.7.3 is out.<br />
<br />
<span class="bold"><a href="https://www.teeworlds.com/?page=downloads&amp;id=12809">Download 0.7.3 now!</a></span><br />
<br />
Here is a short list of the bigger changes we made in those past four months: <br />
<br />
+ advanced scoreboard with game statistics<br />
+ joystick support (experimental!)<br />
+ copy paste (one-way)<br />
+ bot cosmetics (a visual difference between players and NPCs)<br />
+ chat commands (type / in chat)<br />
+ players can change skin without leaving the server (again)<br />
+ live automapper and complete rules for 0.7 tilesets<br />
+ audio toggling HUD<br />
+ an Easter surprise...<br />
<br />
We also patched three (client-sided) security vulnerabilities.<br />
As usual, a complete list of changes and fixes can be found on <a href="https://www.teeworlds.com/forum/viewtopic.php?id=12806">the detailed changelog</a>.<br />
<br />
Happy Easteer!
